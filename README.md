# Find My Pet Cyprus

Missing, found and adoptable pets across Cyprus — map search, filters, reporting and moderation.

**Live site:** https://sarotan420-byte.github.io/find-my-pet-cyprus/

- Pages: `index.html` (map), `missing.html`, `found.html`, `adopt.html`, `submit.html`, `listing.html`, `account.html`, `moderation.html`
- Database setup: `supabase/setup.sql` (run once in Supabase → SQL Editor)
- Supabase keys: `config.js` (empty = demo mode with sample pets, nothing saved)
- Data layer used by every page: `api.js`
- Demo data and option lists: `data.js`
- Full design and build notes: `DESIGN-NOTES.md`, `BUILD.md`
- The previous Astro version is kept on the `backup-old-astro-site` branch.
